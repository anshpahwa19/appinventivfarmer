# Direction 02 photo files

The images here now are AI-generated concept images for the design review
(see `docs/photo-shot-list.md`). Replace each with a licensed photo of the
same name before launch.

Drop licensed photographs here, named after their slot id (see `../catalog.ts`),
for example `harvest-baler.jpg`. Supported: .jpg, .jpeg, .png, .webp, .avif.

Then add the credit to `../credits.ts`. The slot uses the file everywhere it
appears, cropped around the slot's focal point.

Recommended export: 1600 px on the long edge, WebP or AVIF, under 250 KB.
